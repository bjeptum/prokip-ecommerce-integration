Connect Shopify Store

How to Connect Your Shopify Store

  1. Enter your Shopify store URL (e.g., mystore.myshopify.com)
  2. Click "Connect Store" to start the OAuth process
  3. You'll be redirected to Shopify to approve the connection
  4. Once approved, you'll be redirected back and the store will be connected
Enter your Shopify store URL without https://

Connect WooCommerce Store

Connect without API keys

  1. In WordPress, open Users → Your Profile.
  2. Create an Application Password (name it “Prokip Sync”).
  3. Copy the generated password and paste it below with your admin email/username.
  4. Click Connect – you’ll stay in Prokip, no secret keys needed.
Prokip will request:
  • Read products & orders
  • Update stock levels
  • Register inventory webhooks
Used only for display in your connected stores list
